# Delivery Phases

1. **Phase 0 — Foundation (current):** secure desktop shell, local agent, contracts, health flow, tests, and documentation.
2. **Phase 1 — Voice Reactive UI:** assistant state visuals and reactive JARVIS orb.
3. **Phase 2 — Local Audio Engine:** local capture, VAD, wake word, and audio plumbing.
4. **Phase 3 — Gemini Live Voice:** controlled realtime voice integration.
5. **Phase 4 — Desktop Tool Engine:** explicit, permissioned desktop tool registry.
6. **Phase 5 — Token-Efficient AI Router:** local/cloud routing and context controls.
7. **Phase 6 — Developer Agent:** constrained developer workflows.
8. **Phase 7 — Vision / Computer Agent:** screen understanding and approved interaction.
9. **Phase 8 — Memory + Custom Routines:** user-controlled memory and routines.
10. **Phase 9 — Security & Reliability:** hardening, confirmations, recovery, and auditing.
11. **Phase 10 — Desktop Product / Installer:** packaging, updates, and Windows distribution.

Only Phase 0 is implemented. Later phases describe sequencing, not current functionality.

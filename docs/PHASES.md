# Delivery Phases

1. **Phase 0 — Foundation (complete):** secure desktop shell, local agent, contracts, health flow, tests, and documentation.
2. **Phase 1 — Voice Reactive UI (complete):** state-driven HUD, reactive orb, simulated waveform, interaction display, simulator, and compact preview.
3. **Phase 2 — Local Audio Engine (complete):** microphone capture, metrics, waveform input, local VAD, devices, permissions, and cleanup.
4. **Phase 3 — Gemini Live Voice (complete/current):** explicit Live sessions, 16 kHz speech input, native audio output, transcripts, multilingual conversation behavior, barge-in, and lifecycle recovery.
5. **Phase 4 — Desktop Tool Engine (next):** explicit, permissioned desktop tool registry.
6. **Phase 5 — Token-Efficient AI Router:** local/cloud routing and context controls.
7. **Phase 6 — Developer Agent:** constrained developer workflows.
8. **Phase 7 — Vision / Computer Agent:** screen understanding and approved interaction.
9. **Phase 8 — Memory + Custom Routines:** user-controlled memory and routines.
10. **Phase 9 — Security & Reliability:** hardening, confirmations, recovery, and auditing.
11. **Phase 10 — Desktop Product / Installer:** packaging, updates, and Windows distribution.

Phases 0–3 are implemented. Phase 4 is next; later phases describe sequencing only.

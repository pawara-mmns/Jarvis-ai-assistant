# Delivery Phases

1. **Phase 0 — Foundation (complete):** secure desktop shell, local agent, contracts, health flow, tests, and documentation.
2. **Phase 1 — Voice Reactive UI (complete):** state-driven HUD, reactive orb, interaction display, simulator, and compact preview.
3. **Phase 2 — Local Audio Engine (complete):** microphone capture, waveform analysis, local VAD, device handling, and cleanup.
4. **Phase 3 — Gemini Live Voice (complete):** long-lived Live sessions, PCM voice I/O, transcripts, multilingual conversation, barge-in, and recovery.
5. **Phase 4 — Safe Desktop Tool Engine (complete):** validated Gemini function calling, seven approved Windows tools, result-grounded speech, executing UI, limits, and audit logging.
6. **Phase 4.1 — Smart Folder + Application Resolution (complete/current):** trusted-root indexing, aliases, deterministic fuzzy matching, ambiguity handling, Start Menu discovery, and recent resolution caches.
7. **Phase 5 — Token-Efficient AI Router (next):** local/cloud routing and context controls.
8. **Phase 6 — Developer Agent:** constrained developer workflows.
9. **Phase 7 — Vision / Computer Agent:** screen understanding and approved interaction.
10. **Phase 8 — Memory + Custom Routines:** user-controlled memory and routines.
11. **Phase 9 — Security & Reliability:** hardening, confirmations, recovery, and auditing.
12. **Phase 10 — Desktop Product / Installer:** packaging, updates, and Windows distribution.

Phases 0–4.1 are implemented. Later phases describe sequencing only.

# UI Direction

Phase 0 intentionally uses a minimal development status screen. It shows desktop readiness, agent connection state, service identity, version, and a retry action.

The shared future assistant states are:

```text
sleeping
idle
listening
thinking
executing
speaking
confirmation
error
```

Phase 1 will map these states to a voice-reactive JARVIS orb, motion, and accessible status feedback. Phase 0 defines only the state contracts; it does not implement transitions, audio visuals, waveform animation, or final visual design.

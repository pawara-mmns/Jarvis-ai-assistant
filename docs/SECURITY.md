# Security Foundation

- Electron keeps `contextIsolation: true`, `nodeIntegration: false`, and renderer sandboxing enabled.
- Main grants media permission only to the trusted JARVIS renderer and only for audio.
- Preload exposes two typed operations: backend health and ephemeral local Live connection details. It exposes no raw IPC.
- Python binds only to `127.0.0.1`.
- The Live WebSocket accepts a fixed typed audio/session protocol, not commands or code.
- A cryptographically random bridge token is generated by Electron main for each launch, passed to the managed Python child, and required in `session.start`. It is not logged or persisted.
- `GEMINI_API_KEY` is loaded by Python as a secret value. It is never included in preload, renderer bundles, `VITE_*` variables, messages, UI, or logs.
- Audio leaves the device only during an explicitly connected AI session and only after local VAD detects speech. Disconnect closes the remote session.
- Audio is not recorded to disk. Transcripts remain in current in-memory UI/session state.
- Gemini receives no desktop tools in Phase 3 and cannot execute OS actions.

Future tools must use an explicit schema registry, local policy checks, and confirmations; none are present yet.
